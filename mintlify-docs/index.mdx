## What's New (April 23, 2026)

- **Factory AI Unification** — The platform is now 100% unified on Railway infrastructure with a high-energy "Factory Orange" aesthetic.
- **Identity is a Fact** — Transitioned to DID-native cryptographic signatures (`SignatureGuard`). Every request is verified onchain.
- **MiMo V2 Pro Master** — Integrated Xiaomi MiMo V2 Pro as the default "Factory Master" model via a managed Vercel AI Gateway.
- **Bitcoin Sovereignty** — Added support for Zpub/Xpub registration and secure Greenlight PEM certificate management for mainnet Lightning nodes.
- **Durable Execution** — Orchestration moved to Vercel Workflow DevKit for resilient, resumable execution logs.
- **Agentbot Coach** — A new interactive training dashboard at `/dashboard/coach` for teaching new operators.

## The Fact-Based Backend

Agentbot has shifted from legacy patterns to a **Fact-Based Architecture**, ensuring decentralization and verifiable trust.

1. **Identity (Fact):** No leakable keys. All actions are DID-signed.
2. **Execution (Fact):** Durable, resumable workflows replace brittle, stateless routes.
3. **State (Fact):** SQL Hot Storage is mirrored to Gitlawb for an immutable audit trail.
