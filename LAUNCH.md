## Description (short — 260 chars)

Deploy an autonomous AI agent that runs 24/7. Connects to Telegram, Discord, WhatsApp, and X. Built on Vercel with Next.js 16. Features: AI Playground, JSON Render (generative UI), Coding Agent, Automations with MCP integrations, and OpenClaw runtime.

## What is Agentbot?

Agentbot is an open-source AI agent platform. Give it a task, and it runs autonomously — writing code, managing social media, monitoring alerts, triaging issues, and more. Your agent works while you sleep.

## Key Features for Launch

### 1. AI Playground

Build full-stack apps with AI. Describe what you want, get a working Next.js app in minutes.

### 2. JSON Render (Generative UI)

Describe a UI in plain English. AI generates a JSON spec that renders as real React components. Edit the JSON or let AI iterate.

### 3. Coding Agent

Autonomous coding agent that writes, tests, and deploys code. Describe what you need and it builds it.

### 4. Automations with MCP

Event-driven workflows that trigger agent sessions automatically. Connect to Slack, GitHub, Linear, Sentry, Datadog, Notion, Jira, and Figma.

### 5. OpenClaw Runtime

24/7 autonomous agent runtime. Connects to Telegram, Discord, WhatsApp, and X. Does things on your behalf.
