# Bankr — AI-Powered Crypto Trading

Agentbot integrates with Bankr for natural language crypto trading, portfolio management, and DeFi operations. Users connect their own Bankr API key in Settings.

## Setup

1. Get a Bankr API key at https://bankr.bot/api-keys (enable Wallet & Agent API access)
2. Add it in Agentbot: **Settings → Bankr Key**
3. Ask your agent to trade, check balances, or manage your portfolio

## Capabilities

- **Token Swaps** — Buy/sell/swap across Base, Polygon, Ethereum, Solana, Unichain, Arbitrum, BNB Chain
- **Portfolio** — Real-time balances and USD values across 8 chains
- **Transfers** — Send to addresses, ENS names, or social handles
- **Market Research** — Prices, technical analysis, trending tokens
- **Automation** — Limit orders, stop loss, DCA, TWAP, scheduled commands
- **Token Launch** — Deploy ERC-20 on Base or SPL on Solana
- **LLM Gateway** — Multi-model AI access (Claude, GPT, Gemini) at llm.bankr.bot

## Plans

AI prompts require **Bankr Club** or **Max Mode**. Portfolio/balance checks (Wallet API) work on all plans.

- Standard: 5 free messages, then upgrade required
- Bankr Club: 1,000 agent messages/day
- Max Mode: pay-as-you-go premium

Upgrade at https://bankr.bot

## Security

- Your key stays in your Agentbot settings — agents only access your wallet
- Wallet-level spending limits ($500/day default)
- Read-only keys available for monitoring bots
- See https://bankr.bot for security settings
