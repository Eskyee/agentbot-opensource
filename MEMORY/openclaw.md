# OpenClaw

Open-source personal AI agent framework that hit 300K+ GitHub stars. Proves massive demand for running personal AI agents.

## Relevance to Agentbot
- OpenClaw showed people want to run their own AI agents
- Running locally hits limits — no scaling, no uptime, no production readiness
- Agentbot solves this by providing dedicated server infrastructure for agent fleets
- NVIDIA announced NeMoClaw (enterprise version) in March 2026, validating the space

## Key talking point
"OpenClaw proved the demand. Agentbot provides the infrastructure."
